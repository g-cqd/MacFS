# 0006 — Signing with the FSKit Module capability

`com.apple.developer.fskit.fsmodule` needs a provisioning profile carrying the FSKit Module capability for each module's App ID
(Everest reports the same block). Needs the account owner: enable the capability, then build signed and enable in System Settings.
