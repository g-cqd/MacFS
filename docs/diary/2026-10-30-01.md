## Faults

- Written before their tests: the kernels and the Btrfs reader. Red came afterwards, by mutation. Everything from NTFS on was red first
  against a stub.
- `FSError` clashed with FSKit's own type; renamed `DiskError`. BSD `sed` has no `\b`: the first rename did nothing (caught by the build).
- XcodeGen did not substitute template attributes in source paths; `${target_name}` does. Plists are generated instead.
- A stale DerivedData after a failed build copied extensions without their Info.plist; a clean build succeeded.
- An aemi pin conflict (AemiRegex pins `04e49d1`): one pin everywhere (ADR-0004).
- The NTFS short name `ntfs3g-ro` named a project this is not; now `ntfsro`.
- `swift format` re-wrapped a signature and moved a dolly anchor away from its accept directive.
- The machine's pre-commit hook blocked the first commit: it lints manifests and `Benchmarks/`, which the format gate skipped.
  Test first (red, four issues), then the gate widened.
- A misread: `ask` and `TerminalKit` vanished from `~/Developer` mid-session (not this session's doing); cloned from GitHub to `/tmp/refs`.
