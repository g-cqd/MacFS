| Claim | Probe | Verdict |
|---|---|---|
| The images exercise every checksummed structure | read the layout | **REFUTED**: no file had an extent block outside its inode, and every image stored its seed (`csum_seed`), so the UUID path met no disk. Added `big/islands.bin` and `ext4-uuid-seed`; a test asserts both, and an htree directory |

`DiskBytes.region` gives checksums a bounds-checked slice without a copy; `CRC32C.update` takes a buffer pointer for stack copies.
