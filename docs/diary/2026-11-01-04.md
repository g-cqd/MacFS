# Diary — 2026-11-01 (04)

## The agent in the app (roadmap 0039): descriptors, registration, and the sandbox rule that changed ADR-0013

| Claim | Probe | Verdict |
|---|---|---|
| The app can hand the agent the image, not its path | `XPCDictionary` subscripts (macOS 27): descriptors and raw bytes | Holds: XPC duplicates the descriptor. Live: while mounted the agent holds one handle on the image, none after the unmount |
| Every handed descriptor is closed exactly once | `DescriptorProbe` (a pipe: EPIPE once the read end is closed); 6 hand mutants dropping each close | Holds, all 6 killed. **REFUTED** at first in the tests themselves: `fcntl(fd, F_GETFD)` saw a number another parallel test had reused at once |
| The agent can be unsandboxed (ADR-0013 #6) | `SMAppService.agent.register()` from the sandboxed app; backgroundtaskmanagementd's log | **REFUTED**: "SMAppService target executable must be sandboxed because the app is sandboxed". ADR-0016 supersedes ADR-0013 |
| A sandboxed agent cannot mount | the bundled agent, sandboxed with its Info.plist in the binary, registered by the app; `MacFS --mount-image` of an image in the app's container | **REFUTED**: it ran `mount_nfs`; the mount read `random.bin` with the reference manifest's SHA-256 after the app had exited; unmounted through the app. A bare sandboxed tool trapped in `_libsecinit_appsandbox` (no Info.plist) |
| A shell can drive registration | `MacFS --register-agent` run directly | **REFUTED**: "Operation not permitted"; through `open -a MacFS --args` it registers (`enabled`) |
| `log show` printed nothing, so the app logged nothing | `log show` in zsh | **REFUTED**: `log` is a zsh reserved word (AGENTS.md says so); `/usr/bin/log` showed every line |
| Bytes go into an `XPCDictionary` through its subscript | `d["k"] = a.span.bytes`, reduced to one line | **REFUTED**: the Swift 6.4 compiler crashes in SILGen (both toolchains); the C `xpc_dictionary_set_data` is used. Not reported: swiftlang is not a g-cqd repository |

Reduced crash: `import XPC; @available(macOS 27, *) func f(_ a: [UInt8]) -> XPCDictionary { var d = XPCDictionary(); d["k"] = a.span.bytes; return d }`.

Not verified: approval when macOS asks the user to approve the agent (here it was enabled at once); Finder's presentation of a mount
in the agent's container; agent mounts are not in the `mounts` plugin yet.
