# Diary — 2026-11-01 (05)

## The app crashed at launch: an XPC session released without being cancelled

Reported by the user: "the app crashes though". Three identical reports (15:16:40): `_xpc_api_misuse` ←
`-[OS_xpc_session _xref_dispose]` ← `XPCSession.__deallocating_deinit` ← `Mounts.run(_:)`.

| Claim | Probe | Verdict |
|---|---|---|
| A client can be dropped once its calls are done | `AgentConnection.client()` returned an `AgentClient` holding the session, never cancelled; the app lists mounts at launch once the agent is enabled | **REFUTED**: libxpc traps when an active session is released uncancelled. The scripted checks (`--mount-image`, `macfs-agent call`) `exit()` before the release, so the live checks passed and missed it |
| A test can reproduce it with a service nobody provides | a child process (`#expect(processExitsWith:)`) calling an unknown Mach service | **REFUTED**: that session never activates, so releasing it is legal; the test passed. An anonymous `XPCListener` in the same process, reached by its endpoint, activates it: SIGTRAP, red |
| `withClient`, cancelling on the way out, fixes it | the same test; the `cancel` removed again as a mutant | Holds: green; the mutant is SIGTRAP again |
| An empty reply comes back as a reply | `list()` of no mounts over XPC | **REFUTED**: the subscript read an empty data value as absent, "the agent's reply has no bytes"; an empty protobuf message is empty. `XPCDictionary.bytes(for:)` reads through the C API |
| The image descriptor crosses XPC | a pipe sent with a mount; the fake backend's descriptor compared by device and inode | Holds: another number, the same file; the caller's own stays open |

Mutants: no cancel, empty data read as absent, the client not sending the descriptor, the listener not passing it on: all four
killed. A `try!` in an exit-test body traps too (SIGTRAP), so the bodies report failures by exit status (3, 4, ...).

Live: Release installed, the app opened normally with the agent enabled, kept running with no new crash report; mounted, read and
unmounted an image through it; FSKit 18/18.
