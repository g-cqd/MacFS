## What macOS does with our disks, and an installer that installs what it tested (roadmap 0021, 0041)

| Claim | Probe | Verdict |
|---|---|---|

| The installed modules are the ones that run | `pluginkit -mAv`, the module processes' paths | **REFUTED**: registered and run from `/tmp/macfs-release`; every earlier `mounts` run tested the build folder's copy (the same build) |
